The visual system

Colors, type, components and one motion sample for the AIAT website. Every piece on this page is built from the same CSS the real pages will use.

01 — Palette

Teal, ivory and gold

Taken from the logo. Ivory instead of white, teal for weight, gold only as a thin accent.

Muharram mode

Used for the Muharram chapter and, during the month of Muharram, the top of the homepage.

Text contrast (WCAG AA)

These ratios are measured live in the browser from the CSS variables, so they stay correct if a color is retuned. AA needs 4.5 for normal text, 3 for large text and UI lines.

10 — For review

Decisions for Mueez

  1. --gold-text darkened from #8A6631 to #805D2B. The original failed AA (4.2:1) on the --paper-2 card color. The new value passes on all three light surfaces and looks almost the same.
  2. Crimson is used as a fill, not for text. #7A1F1F on the near-black background is only 1.9:1, so in Muharram mode it's used for button and badge fills (with light text, 7:1), hairlines and the top rule of cards. Secondary text there uses a new --mourning-muted (#9C9893, 6.8:1).
  3. Added helper tokens within the existing roles: --mourning-2 (raised cards in Muharram mode), --line-strong (form field borders need 3:1), and two status colors for class cards (--status-open, --status-full).
  4. Years appear without counting up from zero. In the proof sequence, 1992 and 2018 count over a short range, so they read as dates, not as numbers racing up. Counts like 10 and 6 rise from zero.
  5. Logo: images/logo.png isn't in the folder yet, so a simple line mark stands in at the top of this page.
  6. Fonts: the four fonts from the brief work well together. No alternative is proposed.
